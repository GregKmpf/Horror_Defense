## 👁️ Sobre o Projeto

**Horror Defense** combina a tensão de um ambiente de terror com a estratégia de jogos de defesa de torre/base. Monte suas barricadas, gerencie recursos escassos e resista às ondas de criaturas que se escondem nas sombras.
